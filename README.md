# Gothic

A dark, minimalist VS Code theme with a stark, gothic aesthetic. Black, gray, and blood-red combine for a distraction-free coding experience with pure intensity.

## Features

- Dark / White backgrounds with high contrast for improved readability
- Strategic use of red accents for important syntax elements
- Minimal color palette to reduce visual noise
- Designed for extended coding sessions with reduced eye strain

## Installation

1. Open **Extensions** sidebar in VS Code (`Ctrl+Shift+X` / `⌘+Shift+X`)
2. Search for `Gothic`
3. Click **Install**
4. Open the Command Palette (`Ctrl+Shift+P` / `⌘+Shift+P`)
5. Select **Preferences: Color Theme** and choose **Gothic**
